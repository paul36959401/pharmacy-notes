  • 寫法：每個考點寫成「因為…所以…」。課本沒寫、但國考常考的點標「課本外補充」。
  • 讀法：先讀第一、二章建立直覺 → 看第三章地圖 → 各論只記「它打哪裡」，其餘用推的 → 最後用速查表和練習題驗收。

三條萬用推理規則

  1. 血壓 = 心輸出量 × 周邊阻力。想成「水壓 = 幫浦打出的水量 × 水管有多窄」；腎臟另外管「整座城市總共有多少水」。
  2. 每顆降壓藥都在拆掉一個正常的調壓零件，身體會用其他零件反撲（心跳變快、留鈉留水、renin 上升）。所以單一藥效果有限，常要合併。
  3. 利尿劑看「堵在腎元哪一段」：那一段原本回收什麼，就會掉什麼；被送到集尿管的鈉越多，K⁺、H⁺ 被換出越多。

第一章 血壓是怎麼來的：幫浦、水龍頭、儲水袋、淨水廠

血壓由四個控制點決定，再由兩套自動系統（快的神經、慢的腎臟）拉回設定值；高血壓病人只是「設定值被調高」，機制和正常人一樣。所以每一類降壓藥都是在干擾這些正常機制。

四個控制點（課本圖 11–1）

控制點生活比喻它管什麼打它的藥
小動脈（arterioles）水龍頭阻力：轉緊就壓力高α1 blocker、血管擴張劑、CCB、ACEI、ARB
小靜脈（venules，容量血管）儲水袋放鬆就把血存起來，回心的血變少α1 blocker、nitroprusside、硝酸鹽

腎臟淨水廠全身總血量（長期血壓的主管）利尿劑、醛固酮拮抗劑
  • 因為多數原發性高血壓是「水龍頭轉太緊」（周邊阻力高、心輸出量正常），所以降壓的主戰場在小動脈。
  • 因為只有 10–15% 找得到原因（續發性），所以要先排除可以開刀治好的：腎動脈狹窄、主動脈窄縮、嗜鉻細胞瘤、Cushing 病、原發性醛固酮症。

快系統：壓力感受器反射（水管上的壓力錶＋自動警報）

  • 腦幹的交感中樞平常一直在放電（油門輕踩著）。頸動脈窦的壓力感受器被血壓「撐開」時，會叫中樞踩煞車。
  • 因為站起來時血往腳流、血管壁被撐得比較少，所以煞車鬆開 → 交感神經增加 → 小動脈收緊、心跳加快、靜脈收縮把血擠回心臟 → 血壓回來。
  • 因為這套反射對「任何讓血壓下降的事」都會反應（包括血管擴張劑、失血、利尿劑脱水），所以吃血管擴張劑會反射性心跳加快。
  • 反過來，因為打在周邊交感神經的藥會把這套反射拆掉，所以它們會造成姿勢性低血壓；直接血管擴張劑保留反射，所以不會。

慢系統：腎臟管水量（淨水廠經理）

  • 腎臟灌流壓下降，或交感神經經 β1 刺激 → 腎臟放出 renin → 做出 angiotensin II（Ang II）。
  • Ang II 做兩件事：直接把小動脈轉緊；叫腎上腺皮質放醛固酮 → 腎臟留鈉 → 血量變多。
  • 腦下垂體後葉的 ADH（vasopressin）管「留水」。
  • 因為腎臟掌管總血量，所以它是「長期」血壓的老闆；神經反射是秒級的微調。

為什麼常要合併用藥（課本圖 11–4）

因為降壓藥都在干擾正常機制，所以身體會反撲。以血管擴張劑（如 hydralazine）為例：

  1. 阻力下降 → 血壓下降。
  2. 壓力感受器發現 → 交感上升 → 心跳加快、收縮變強、靜脈收縮 → 心輸出量上升。→ 加 β blocker 擋。
  3. renin 上升 → Ang II、醛固酮上升 → 留鈉留水、血量變多。→ 加利尿劑擋。

所以 hydralazine、minoxidil 常和 β blocker＋利尿劑一起用，三顆藥會讓彼此更有效。

  • 因為交感抑制劑和血管擴張劑會讓血管失去收放彈性，變成「一根硬水管」，所以血壓對血量變得超敏感：血量 95% 時控制良好，105% 時就太高。這就是重度高血壓幾乎都要加利尿劑的原因。
  • 另兩個合併理由：有些藥降壓幅度不大但長期保護很重要（例如 ACEI 常 < 10 mm Hg）；有些藥毒性太大，不能用到最大劑量。
  • 課本估計最多 40% 病人用兩顆藥仍不夠（頑固型高血壓），需要三顆以上。

第二章 腎臟淨水廠：腎元為什麼要分成這幾段？

腎元是一條「先大量回收 → 製造鹹的髓質 → 稀釋 → 最後由荷爾蒙微調」的回收產線；利尿劑堵在哪一段，就丟掉那一段原本回收的東西。

【圖1】

照編號 1 → 6 走一遍：上游收得多但下游會補，越下游越靠荷爾蒙微調；4 粗升支收得多、又負責把髓質弄鹹，所以擋它的 loop 最強。

整條產線的設計邏輯

  • 因為腎絲球一天濾出一大缸水（約 180 L，課本外補充），裡面混著鈉、碳酸氫根、葡萄糖等寶貝，所以第一站要「大宗、快速」搶回來，不做精細調整。
  • 因為身體有時要排濃尿、有時要排稀尿，所以中段先把髓質弄得很鹹（像在地下室堆鹽），下游才有本錢把水吸回來。
  • 因為最後的尿量、尿鈉、尿鉀必須依身體當下需要決定，所以「荷爾蒙開關」放在最後一站：調完就直接出貨，不會再被下游改掉。
  • 推出利尿劑強弱：藥效 ≈ 那一段的回收量 × 下游補不回來的程度。所以 loop（TAL）最強，thiazide（DCT）中等，保鉀（集尿管）較弱；PCT 回收量雖大，但下游會補收，所以 acetazolamide 反而很弱。

① 腎絲球：濾網

只過濾、不挑選；後面每一段都在從濾液把東西撿回來。

② 近曲小管（PCT）：大宗回收站

做什麼：收回約 65% 的 Na⁺、65% 的 K⁺、85% 的 NaHCO₃、幾乎 100% 的葡萄糖和胺基酸。水的通透性極高，水跟著溶質走（等滲回收）。

  • HCO₃⁻ 怎麼搬（課本圖 15–2）：HCO₃⁻ 帶電、穿不過細胞膜。因為管腔的碳酸酐酶（CA）先把它「拆包裝」成 CO₂＋H₂O，CO₂ 可以直接溜進細胞，進去後再由細胞內的 CA 組回 HCO₃⁻，所以 HCO₃⁻ 的回收完全靠 CA。→ acetazolamide 擋 CA，HCO₃⁻ 就掉進尿裡。
  • 管腔的 NHE3（Na⁺/H⁺ 交換）把 Na⁺ 收進來、H⁺ 吐出去；吐出去的 H⁺ 正好拿去和 HCO₃⁻ 組合。底側的 Na⁺/K⁺-ATPase 再把 Na⁺ 打回血液（每一段都有這台「排水馬達」）。
  • SGLT2：把葡萄糖和 Na⁺ 一起收回。擋住它，葡萄糖留在管內拉住水（滲透性利尿）。
  • 直段（S2）有「有機酸分泌窗口」：尿酸、NSAIDs、多數利尿劑、抗生素都從血液被丟進管腔。
    • 因為大多數利尿劑要從「管腔那一側」作用，所以它們必須先被這個窗口送進管腔。→ NSAIDs、probenecid 搶窗口，利尿劑效果變差。
    • 因為 thiazide、loop 也搶這個窗口，尿酸排不出去，所以血尿酸上升、可能誘發痛風。

為什麼打這裡的利尿劑很弱：因為下游各段會把漏掉的鈉補收回來，而且 HCO₃⁻ 掉光後濾液裡沒東西可丟，所以 acetazolamide 的利尿作用 2–3 天就沒了。

③ 細降支：只透水的管子

  • 水通透性高；因為外面的髓質很鹹，水被吸出去，管內液越走越濃。
  • 因為這段（和 PCT）水能自由進出，所以「不被回收的溶質」像 mannitol 放在管內，就能把水留住 → mannitol 主要作用在 PCT 和細降支。
  • 細升支則相對不透水、可讓部分溶質通過。

④ 粗升支（TAL）：抽鹽不抽水的製鹽廠（稀釋段）

做什麼：用 NKCC2（Na⁺/K⁺/2Cl⁻ 同向運輸）主動收回 15–25% 的 Na⁺，但幾乎不透水。

為什麼這樣設計：

  • 因為「只收鹽、不收水」，所以管內液被稀釋（稱稀釋段），收回來的鹽堆在髓質，讓髓質變鹹。鹹的髓質是集尿管濃縮尿的本錢。
  • 因為 K⁺ 被 NKCC2 帶進細胞後會從 ROMK 通道漏回管腔，所以管腔帶正電；這股正電把 Ca²⁺、Mg²⁺ 從細胞縫隙「推」回血液（像擠滿人的車廂把人推出門）。

推理：

  • loop 利尿劑擋 NKCC2 → 少收大量的鈉，下游又補不回來 → 最強的利尿劑（高天花板）。
  • 擋了 NKCC2，K⁺ 不再回流 → 腔內正電消失 → Ca²⁺、Mg²⁺ 推不回去 → 尿鈣、尿鎂上升。
  • 髓質不再鹹 → 集尿管無法濃縮 → 鹽和水一起丟（所以 loop 比 thiazide 少造成低血鈉；髓質濃度這個解釋是課本外補充的生理推論）。

⑤ 遠曲小管（DCT）：精修站

做什麼：用 NCC（Na⁺/Cl⁻ 同向運輸）收回約 4–8% 的 Na⁺（內文說約 10%），也不透水，所以繼續稀釋。

  • 因為這裡沒有 K⁺ 回流、沒有腔內正電，所以 Ca²⁺ 要另走「專用門」：管腔的 Ca²⁺ 通道進、底側的 Na⁺/Ca²⁺ 交換器出，由 PTH 控制。
  • 推理：thiazide 擋 NCC → 細胞內 Na⁺ 變少 → 底側 Na⁺/Ca²⁺ 交換器更賣力把 Na⁺ 換進來、Ca²⁺ 換出去（回到血液）→ 尿鈣下降。所以「loop 掉鈣、thiazide 留鈣」。
  • 因為 DCT 在皮質、不負責製造鹹髓質，thiazide 擋它時髓質還是鹹的，ADH 仍能把水吸回 → 丟鹽卻留水 → thiazide 是最常造成低血鈉的利尿劑。

⑥ 集尿管：最後品管站（荷爾蒙在這裡下指令）

做什麼：只收 2–5% 的 Na⁺，卻決定最後的尿量、尿鈉，並負責幾乎所有的 K⁺ 分泌。

兩種細胞：主細胞（principal cell）管 Na⁺、K⁺、水；間細胞（intercalated cell）管 H⁺（α 細胞）或 HCO₃⁻（β 細胞）。

醛固酮的作用：

  • 主細胞沒有同向運輸，只有分開的 Na⁺ 通道（ENaC）和 K⁺ 通道。因為 Na⁺ 進來多於 K⁺ 出去，管腔變成負電（10–50 mV），這股負電把 K⁺ 拉出細胞、把 Cl⁻ 拉回血液。
  • 醛固酮是「加班令」：透過基因轉錄增加 ENaC 和 Na⁺/K⁺-ATPase → 收更多鈉、排更多鉀和氫。

ADH 的作用：

  • ADH 接上 V2 受體（Gs → cAMP）→ 把預先做好的水通道 AQP2 插到管腔膜上 → 水被鹹髓質吸回 → 濃縮尿。沒有 ADH → 排稀尿。
  • ADH 也插入尿素通道（UT1），幫髓質保持鹹度。血管與中樞是 V1 受體、腎臟是 V2 受體。

為什麼 K⁺ 流失幾乎都發生在這裡（最重要的推理）：

  1. 上游利尿劑（CA 抑制劑、loop、thiazide）讓更多 Na⁺ 抵達集尿管。
  2. 抵達的 Na⁺ 被 ENaC 收進來 → 腔內負電更強 → 更多 K⁺、H⁺ 被拉出去。
  3. 脱水又讓醛固酮上升 → 再加碼。

所以：上游利尿劑 → 低血鉀＋代謝性鹼中毒；擋這裡的保鉀利尿劑 → 高血鉀＋代謝性酸中毒。若 Na⁺ 搭配的是不好回收的陰離子（例如 acetazolamide 時的 HCO₃⁻），腔內負電更強、K⁺ 掉更多。飲食限鈉反而能減少鉀流失，因為送到集尿管的 Na⁺ 變少了。

腎內的「調節小幫手」（課本 Renal autacoids）

  • PGE2：減少 TAL 收鹽、減弱 ADH 的水回收 → 幫 loop 利尿劑出力。因為 NSAIDs 擋前列腺素合成，所以會削弱 loop（腎病症候群、肝硬化病人特別明顯），也可能削弱 thiazide 和保鉀利尿劑。
  • Adenosine（A1 受體）：缺氧時讓入球小動脈收縮、GFR 下降，是腎小管—腎絲球回饋的關鍵訊號。adenosine 拮抗劑有利尿作用且不掉鉀（研究中）。
  • 利鈉胜肽：ANP、BNP（心臟製造）與 urodilatin（腎臟自己做）增加 GFR、減少集尿管收鈉。nesiritide = 重組 BNP；ularitide = 重組 urodilatin（研究中）。

各論一 利尿劑：看它堵在哪一段

先找出堵在哪一段，再問「那段原本收什麼」＋「多出來的鈉會不會衝到集尿管換掉 K⁺、H⁺」，大部分副作用就推得出來。

1. 碳酸酐酶抑制劑（PCT）：拆包裝機壞了

代表藥：acetazolamide（口服）；dorzolamide、brinzolamide（眼藥水，不影響全身）；methazolamide、dichlorphenamide（口服治青光眼）。

機轉：擋 CA → HCO₃⁻ 無法拆包裝回收 → NaHCO₃ 從尿排掉。

  • 因為鹼性的 HCO₃⁻ 被尿帶走，所以尿變鹼、身體變酸：高氯性代謝性酸中毒。
  • 因為 HCO₃⁻ 掉光後濾液裡沒得丟、下游又會補收 NaCl，所以利尿效果只撐 2–3 天；但酸中毒會持續到停藥。最大劑量也只擋全腎約 45% 的 HCO₃⁻ 回收。
  • 因為眼睛睫狀體做房水、脈絡叢做腦脊髓液也要靠 CA 分泌 HCO₃⁻，所以它能降眼壓、減少腦脊髓液。

用途：

  • 青光眼（最常見的適應症）。
  • 急性高山症：腦脊髓液和腦部變酸 → 刺激呼吸 → 改善症狀；同理可用於睡眠呼吸中止。
  • 尿液鹼化：胱胺酸尿症（pH 7–7.5）、尿酸結石（pH 6–6.5）；但不補 HCO₃⁻ 只有 2–3 天效果。
  • 代謝性鹼中毒：心衰竭病人利尿劑造成鹼中毒、又不能補生理食鹽水時。
  • 其他：癫癇輔助、低血鉀週期性麻痺、腦脊髓液滲漏、特發性顱內高壓、Ménière 病、嚴重高磷血症。

副作用：

  • 代謝性酸中毒（上面推過）。
  • 腎結石：因為尿鈣、尿磷增加，檬檬酸減少，加上鹼性尿裡磷酸鈣很難溶，所以容易長磷酸鈣結石。
  • 低血鉀：因為送到集尿管的 Na⁺ 搭的是 HCO₃⁻（不好回收），腔內負電更強 → K⁺ 被拉出；也會低血磷。→ 長期用要監測血鉀、血磷。
  • 大劑量嗜睡、感覺異常（手腳麻）；腎衰竭時蓄積造成神經毒性。
  • 磺胺類過敏：發燒、皮疹、骨髓抑制、間質性腎炎。

禁忌：肝硬化。因為尿變鹼，NH₄⁺ 轉成不帶電的 NH₃ 溜回血液 → 血氨上升 → 肝腦病變。比喻：NH₄⁺ 是綁緊的垃圾袋丟得出去；在鹼性尿裡袋子破了變成 NH₃ 氣體，又飄回家裡。

排除：由 PCT 的 S2 段分泌 → 腎功能不好要減量。

2. SGLT2 抑制劑（PCT）：糖回收門關掉

代表藥：canagliflozin、dapagliflozin、empagliflozin。

  • 因為葡萄糖留在管內拉住水，所以有輕微滲透性利尿：收縮壓平均降約 5 mm Hg、體重平均降約 3 kg。
  • 適應症只有糖尿病，不是拿來當利尿劑。
  • 副作用：女性生殖器黴菌感染約 6 倍、泌尿道感染稍增；低血糖少；有急性腎損傷報告。
  • 因為 Ang II 經 AT1 會增加 SGLT2，所以阻斷 RAAS 可能讓 SGLT2 變少。

3. 滲透性利尿劑（PCT＋細降支）：管子裡塞了一塊不被吸收的海綿

代表藥：mannitol。

  • 因為口服吸收差、只會造成滲透性腹瀉，所以一定要靜脈注射。
  • 因為它被濾出却不被回收，留在「水能自由進出」的 PCT 和細降支裡拉住水，所以尿量大增；水比鈉掉得多 → 最後高血鈉。它也用滲透壓對抗 ADH 的作用。
  • 因為它也把細胞裡的水拉出來，所以能降顱內壓、降眼壓（1–2 g/kg IV，60–90 分鐘見效）。

用途：顱內壓高、眼科手術前降眼壓、溶質負荷大造成的腎衰竭（橫紋肌溶解、化療）；也有人用在剛開始洗腎時。

副作用（照時間順序推）：

  1. 剛打進去：水從細胞被拉到細胞外 → 細胞外液擴張、低血鈉 → 心衰竭病人可能肺水腫。頭痛、噓心、嘔吐常見。
  2. 開始利尿後：水掉太多 → 脱水、高血鈉。
  3. 細胞被抽乾 → 細胞內 K⁺ 濃度上升、流出 → 高血鉀。
  4. 腎功能很差的人排不掉 → 一直留在血中拉水 → 低血鈉（但血清滲透壓不低）。
  5. 急性腎損傷約 6–7%。

4. Loop 利尿劑（TAL）：把製鹽廠的大門關掉

代表藥：furosemide、bumetanide、torsemide（都是磺胺類）；ethacrynic acid（非磺胺類）。

機轉：擋 NKCC2 → 少收大量鈉 → 最強的利尿劑（high ceiling）。因為回收量大、下游補不回來，所以劑量加到常規的好幾倍，降壓效果仍持續增加（和 thiazide 不同）。

藥等效劑量特色
furosemide20 mg口服生體可用率不穩；作用 2–3 小時
torsemide10 mg口服吸收快（1 小時）且完整；作用 4–6 小時；有長效活性代謝物
bumetanide0.5 mg效價最強；靜脈注射偶有注射部位皮膚觸痛
ethacrynic acid約 50 mg不是磺胺類 → 磺胺過敏者可用；靠亞甲基和半胱胺酸的 SH 結合

作用的因果：

  • 因為要從管腔側作用，所以要先被 PCT 分泌進管腔；NSAIDs、probenecid 搶分泌窗口 → 效果變差。
  • 因為 loop 會誘導 COX-2 產生 PGE2 幫忙抑制 TAL 收鹽，所以 NSAIDs（如 indomethacin）也從這條路削弱 loop。
  • 因為擋 NKCC2 讓腔內正電消失，所以 Ca²⁺、Mg²⁺ 從尿掉：長期用會低血鎂；配合生理食鹽水可治高血鈣。通常不會低血鈣，因為維生素 D、PTH 會補。
  • 因為它還會讓腎臟放出前列腺素、使血管擴張，所以急性肺水腫時「還沒開始尿」就先降低肺充血和左心室充填壓；furosemide 也增加腎血流。

用途：急性肺水腫（最重要）、各種水腫（心衰竭、腎病、肝硬化）、腎功能不全或心衰竭的高血壓（GFR < 30–40 mL/min 時改用 loop）、高血鈣、高血鉀、急性腎衰竭（增加尿量但不改善預後）、陰離子中毒（溴、氟、碘在 TAL 回收，要同時補生理食鹽水）。

副作用：

  • 低血鉀性代謝性鹼中毒：更多 Na⁺ 衝到集尿管 → 換出 K⁺、H⁺（最常見）。
  • 耳毒性：劑量相關、多可逆；腎功能差或併用 aminoglycoside 時最危險。
  • 高尿酸、痛風：因為脱水讓 PCT 更用力回收尿酸。
  • 低血鎂：腔內正電消失；飲食缺鎂者最常見。
  • 脱水；低血鈉比 thiazide 少，但口渴猛喝水仍可能低鈉。
  • 過敏：磺胺類 → 皮疹、嗜酸性球增加、間質性腎炎（ethacrynic acid 例外）。
  • 其他：可能加重心衰竭病人的硫胺（維生素 B1）缺乏；多發性骨髓瘤會加重管柱形成；可能高尿鈣。
  • 課本外補充：ethacrynic acid 的耳毒性最強；英文口訣 OH DANG（Ototoxicity、Hypokalemia、Dehydration、Allergy、Nephritis、Gout）。

5. Thiazide（DCT）：精修站的鹽門關掉

代表藥：hydrochlorothiazide（HCTZ，原型）、chlorthalidone、chlorothiazide；indapamide、metolazone 是「類 thiazide」的磺胺類。

機轉：擋 NCC（Na⁺/Cl⁻）→ 中等強度。thiazide 是研發更強 CA 抑制劑時意外發現的，所以部分藥（如 chlorthalidone）仍有 CA 抑制作用。

藥特色
HCTZ最常用的降壓利尿劑
chlorthalidone吸收慢、半衰期 40–60 小時（和紅血球結合），24 小時控壓較好、心血管事件較少 → 課本偏好
chlorothiazide唯一可靜脈注射的 thiazide；脂溶性差、劑量大
indapamide主要經膽汁排除，但仍有足夠活性藥到 DCT
metolazone常和 loop 併用（加乘）；只有口服

作用的因果：

  • 因為回收量不大，所以劑量反應曲線很平：HCTZ 25–50 mg 的降壓效果和高劑量差不多，加量只會增加副作用。
  • 因為細胞內 Na⁺ 下降 → Na⁺/Ca²⁺ 交換加速，加上脱水讓 PCT 多收鈉和鈣，所以 thiazide「留鈣」：可預防高尿鈣造成的鈣結石、可能稍微減少骨質疏鬆骨折；也可能讓原本隱藏的高血鈣（副甲狀腺亢進、癌症、類肉瘤）現形。
  • 因為要經 PCT 有機酸窗口分泌、和尿酸搶位子，所以血尿酸上升。
  • 因為效果也部分依賴前列腺素，所以 NSAIDs 可能削弱它。
  • 因為 GFR < 30 mL/min 時送到 DCT 的鹽太少，所以 thiazide 被認為沒效；但 GFR 5–15 時加在 loop 上，仍可明顯減少 loop 用量。

用途：高血壓（首選之一）、輕度心衰竭、高尿鈣造成的腎結石（要多喝水、限鹽，但不要限鈣）、腎因性尿崩症。

腎因性尿崩症為何反而減少尿量：因為 thiazide 讓血量變少 → PCT 多收鹽水 → 流到稀釋段的水變少 → 能排出的稀尿總量下降；鋰鹽引起的還會提高內髓質滲透壓、部分恢復 AQP2。但因為利尿劑減少鋰的清除，所以要監測血鋰。

副作用「四高三低」（課本外整理，內容來自課本）：

  • 高血糖：高劑量（HCTZ > 50 mg/d）時，因為 thiazide 打開胰臟 β 細胞的 K-ATP 通道（過極化）→ 少放胰島素，組織用糖也變差；低血鉀會加重 → 補鉀可部分逆轉。≤ 12.5 mg/d 沒看到。
  • 高血脂：總膽固醇、LDL 增加 5–15%，長期可能回到基線。
  • 高尿酸：和尿酸搶分泌窗口＋脱水；是最常和痛風連在一起的利尿劑（但大型研究只在 60 歲以下男性增加約 1%）。
  • 高血鈣：留鈣。
  • 低血鉀性代謝性鹼中毒：Na⁺ 衝到集尿管。
  • 低血鈉：最重要的副作用之一。因為脱水讓 ADH 上升、稀釋段被擋、又口渴喝水 → 丟鹽留水。可減量或限水預防；KCNJ1 基因多型性與此有關。
  • 低血鎂（第 11 章：利尿劑可造成鏂流失）。

其他：磺胺類交叉過敏、光敏感或全身性皮膚炎；罕見溶血性貧血、血小板低下、急性壞死性胰臟炎；無力、疲倦、感覺異常；陽痿（多因脱水）；低血鈉引發急性隅角閉鎖性青光眼的個案。

禁忌：肝硬化、邊緣性腎衰竭、心衰竭時「過度」使用任何利尿劑都危險。

6. 保鉀利尿劑（集尿管）：讓品管站不要再拿鉀換鈉

分兩派，差別在「撕命令」還是「鎖門」：

類別代表藥比喻要有醛固酮才有效嗎
醛固酮受體拮抗劑spironolactone、eplerenone（finerenone 研究中）把「加班令」撕掉要
ENaC 阻斷劑amiloride、triamterene直接把鈉門鎖上不用

推理範例：Liddle 症候群是 ENaC 基因突變、鈉門自己卡在打開，不是醛固酮造成的 → 撕命令沒用（spironolactone 無效），鎖門有用（amiloride 有效）。

藥物特色：

  • spironolactone：合成類固醇；靠肝臟產生長效活性代謝物（canrenone 等）→ 起效和退場都慢（作用 24–48 小時）。也強力擋雄性素受體 → 男性女乳症、性慾減退、陽痿。
  • eplerenone：對礦物皮質素受體選擇性高幾百倍 → 幾乎沒有女乳症；但經 CYP3A4 代謝，erythromycin、fluconazole、diltiazem、葡萄柚汁會讓血中濃度大增（spironolactone 不會）。心肌梗塞後心衰竭病人死亡率降約 15%。
  • amiloride：不經代謝、給藥次數少；可治 Liddle 症候群、鋰鹽引起的腎因性尿崩症（因為它也擋鋰從 ENaC 進入細胞）。
  • triamterene：肝代謝、半衰期短、要多次給藥；溶解度差會沉澱成腎結石；和 indomethacin 併用曾造成急性腎衰竭。

用途：

  • 醛固酮過多：原發性（Conn 症候群、異位 ACTH）、續發性（心衰竭、肝硬化、腎病症候群）。
  • 肝硬化腹水：因為肝硬化病人醛固酮特別高、loop 又不容易被分泌到管腔，所以對 spironolactone、eplerenone 反應特別好。
  • 心衰竭、心肌梗塞後：降低死亡率；也可能減少糖尿病白蛋白尿（抗纖維化、抗發炎）。
  • 頑固型高血壓：spironolactone 可能是最有效的加藥選擇。
  • 抵銷其他利尿劑造成的低血鉀。

副作用：

  • 高血鉀（最重要）：因為 K⁺ 不被換出。腎功能差、或併用 ACEI、ARB、aliskiren、β blocker、NSAIDs、鉀補充劑時最危險，嚴重可致命。單獨當利尿劑用時更常見。
  • 高氯性代謝性酸中毒：因為間細胞的 H⁺ 分泌也一起被擋（類似第 IV 型腎小管酸中毒）。
  • 女乳症、陽痿（spironolactone）；腎結石與急性腎衰竭（triamterene）。

禁忌與注意：慢性腎功能不全少用；開始用時停掉口服鉀；肝病會影響 triamterene、spironolactone 代謝。固定劑量複方（如 Aldactazide、Dyazide、Moduretic）因為兩成分的生體可用率不同，常是 thiazide 的副作用佔上風，所以課本建議兩藥分開調劑量。

7. ADH 拮抗劑（集尿管）：把水門的鑰匙收走

代表藥：conivaptan（靜脈，擋 V1a＋V2）、tolvaptan（口服，選擇性 V2）；舊藥 demeclocycline（四環黃素類）、lithium。屬於 aquaretic：只排水不排鈉。

  • 因為 ADH 經 V2 → cAMP → 插入 AQP2，擋掉它就無法回收水，所以排出「沒有溶質的水」→ 血鈉回升。lithium、demeclocycline 則以不明機轉降低 cAMP。
  • 因為 V1a 在血管，conivaptan 擋 V1a 可降低周邊阻力、增加心輸出量 → 心衰竭的低血鈉特別適合。

用途：SIADH（限水無效時；demeclocycline 600–1200 mg/d 或 tolvaptan 15–60 mg/d）、心衰竭的低血鈉、體顯性多囊腎（tolvaptan 減緩腎臟變大）。

副作用：血鈉沒監測好 → 嚴重高血鈉、腎因性尿崩症；口乾、口渴；tolvaptan 低血壓、肝功能上升（肝病相對禁忌）；lithium、demeclocycline 可造成腎衰竭；demeclocycline 避免用於肝病與 12 歲以下兒童。

相反的藥：vasopressin、desmopressin（ADH 致效劑）治中樞性尿崩症。

8. 利尿劑合併

  • loop＋thiazide（常用 metolazone）：因為擋一段時另一段會多收，兩段一起擋就「超過相加」；thiazide 在 PCT 的少量排鈉也不再被 TAL 補回 → 對 loop 無效的病人也可能大量排水。風險：大量脱水、嚴重低血鉀 → 需密切監測。
  • 保鉀＋其他利尿劑：抵銷低血鉀；但腎功能不全、用 ACEI 者避免（高血鉀）。
  • loop 效果變差時，先縮短給藥間隔：因為半衰期只有 2–6 小時，藥效空窗期腎臟會拼命留鈉。

各論二 交感神經抑制劑：讓「油門」鬆一點

先找出它擋在交感反射弧的哪一站（腦 → 神經節 → 神經末梢 → 受體），副作用就照那一站的「管轄範圍」推。

先記四站的副作用性格（課本）

打哪一站比喻招牌副作用原因
腦幹（中樞）關掉總開關嗜睡、憂鬱、惡夢藥在腦裡作用
神經節把轉運站整個封掉交感＋副交感全倒：姿勢性低血壓、性功能障礙、便秘、尿滴留、誘發青光眼、視力模糊、口乾交感與副交感都要經過神經節
神經末梢把 NE 倉庫掏空像手術切除交感神經：站立和運動後低血壓、射精障礙反射要用的 NE 沒了
受體（α1、β）只拆特定插座依受體而定，最有選擇性只擋一種受體
  • 因為所有交感抑制劑都會讓腎臟留鈉、血量變多來抵銷效果，所以最好併用利尿劑。
  • 中重度高血壓的有效組合大多含一顆交感抑制劑。

1. 中樞 α2 致效劑：踩腦幹的煞車

  • 因為腦幹的 α2 受體是「讓交感少放電」的煞車，所以刺激它 → 交感輸出下降、副交感上升 → 血壓降、心跳慢。
  • 因為壓力感受器反射仍保留（甚至更敏感），所以姿勢性低血壓比周邊藥少。
  • 除了 clonidine，這類藥現在很少用。

methyldopa

  • L-dopa 的類似物，經芳香族胺基酸轉運體進腦 → 變成 α-methylnorepinephrine（冒牌 NE）存在囊泡裡。
  • 重點：冒牌 NE 在周邊仍能活化 α 受體讓血管收縮，所以降壓不是靠「冒牌貨」，而是靠它刺激中樞 α2。
  • 因為要先在囊泡累積，所以藥效比血中濃度持久（4–6 小時達最大、可持續 24 小時）。
  • 主要降低周邊阻力，並降低腎血管阻力（腎臟友善）。
  • 現在主要用於：懷孕高血壓。
  • 副作用：嗜睡（開始時最明顯）、長期精神倦怠、專注力下降；Coombs 試驗陽性（用超過 12 個月者 10–20%，交叉配血困難）、罕見溶血性貧血、肝炎、藥物熱；泌乳（男女都會，因為抑制下視丘多巴胺 → 泌乳素上升）；惡夢、憂鬱、眩暈、錐體外症狀較少見。停藥多可恢復。

clonidine

  • 2-imidazoline 衍生物，本來在測試當鼻塞藥時發現；也接 imidazoline 受體。
  • 靜脈注射時：先短暫升壓（直接刺激血管 α 受體），再長時間降壓 → 屬於 α 受體部分致效劑。大量過量時可嚴重高血壓。
  • 和 methyldopa 的差別：clonidine 降心跳、心輸出量更多；脂溶性高、快速進腦；劑量越高越有效（也越毒）。
  • 因為半衰期短、藥效跟著血中濃度走，所以一天兩次，或用貼片（一片 7 天，嗜睡較少、可能皮膚反應）。
  • 副作用：口乾、嗜睡（中樞、劑量相關）；憂鬱風險高者不可用。
  • 最重要：突然停藥 → 反彈性高血壓危象（尤其 > 1 mg/d）。因為長期被壓抑的交感系統一放開就暴衝 → 緊張、心悸、頭痛、冒汗。處理：恢復 clonidine，或給 α＋β 阻斷劑；要停藥必須慢慢減、同時換上其他降壓藥。
  • 交互作用：三環抗憂鬱劑會擋掉 clonidine 的降壓（TCA 有 α 阻斷作用）。
  • 其他用途：濟用藥物的戒斷。
  • guanabenz、guanfacine：同類、沒有優勢、少用。

2. 神經節阻斷劑（如 trimethaphan）

  • 競爭性擋交感與副交感神經節的菸鹼受體，也可能直接堵住通道 → 副作用就是藥理作用本身（見上表），太多而已淘汰。

3. 腎上腺素神經元阻斷劑：讓 NE 倉庫出不了貨

guanethidine：從正門混進去的冒牌貨

  • 因為它和 NE 走同一個正門（NET，uptake 1）進入神經末梢，再取代囊泡裡的 NE，所以會慢慢把 NE 耗光、阻止 NE 釋放。
  • 因為一定要經過正門，所以擋住正門或把胺類擠出來的藥（cocaine、amphetamine、三環抗憂鬱劑、phenothiazine、phenoxybenzamine）會讓它失效。
  • 因為極性太高、進不了腦，所以沒有中樞副作用。
  • 半衰期 5 天 → 起效慢（1–2 週達最大），停藥後也慢；加量間隔不少於 2 週。
  • 副作用：姿勢性低血壓、運動後低血壓、射精延遲或逆行射精（射到膀胱）、腹瀉（交感被拔掉，腸道剩副交感主導）。
  • 交互作用：感冒成藥裡的擬交感藥 → 高血壓；嗜鉻細胞瘤 → 放出兒茶酚胺造成高血壓危象；三環抗憂鬱劑 → 失效並可能嚴重高血壓。
  • guanadrel 類似；bethanidine、debrisoquin 也類似（美國都不用）。

reserpine：倉庫門壞掉

  • 來自印度蛇根木（Rauwolfia serpentina），是最早大量使用的降壓藥之一。
  • 因為它不可逆地擋囊泡單胺轉運體（VMAT），NE、多巴胺、血清素都無法收進倉庫，所以中樞與周邊的單胺都被耗光（腎上腺髓質也會，但較少）。
  • 低劑量：降低心輸出量和周邊阻力；姿勢性低血壓少。
  • 因為它進得了腦、把腦內單胺掏空，所以：嗜睡、倦怠、惡夢、嚴重憂鬱（低劑量也可能，且可能在用藥數月後才出現）→ 有憂鬱病史者禁用；紋狀體多巴胺被耗光 → 類巴金森症狀。
  • 因為交感被拔掉、副交感主導腸胃 → 腹瀉、腸絞痛、胃酸增加 → 消化性潰瘍病史者禁用。

4. β 阻斷劑：讓幫浦轉慢、少放 renin

怎麼降壓：

  • 主要降低心輸出量（擋心臟 β1）。
  • 擋腎臟近腎絲球細胞的 β1 → 少放 renin → RAAS 降下來（renin 高的人最有效，但 renin 正常或低也有效）。
  • 可能也擋突觸前 β 受體、減少交感神經放電。
  • 輕中度高血壓時，沒有明顯姿勢性低血壓。

定位：輕中度高血壓都有效；重度高血壓時用來擋血管擴張劑造成的反射性心跳加快；心肌梗塞後與心衰竭（部分藥）可降低死亡率。但因為降低心血管事件較差，所以目前不建議當單純高血壓的第一線。

  • 因為擋 β1：心搏過慢、傳導阻滞病人會更慢。
  • 因為擋 β2：氣喘病人支氣管收縮、周邊血管疾病惡化、糖尿病要小心。→ 心臟選擇性藥（metoprolol 擋 β2 比 propranolol 弱 50–100 倍）較適合這些人，但選擇性不完全。
  • 課本外補充：β blocker 會遮蔽低血糖時的心悸、顫抖警訊（冒汗仍在）。
  • 停藥症候群：長期用藥後 β 受體變多、變敏感，突然停藥 → 緊張、心搏過速、心絞痛加重、血壓上升，少數心肌梗塞 → 要慢慢減。
  • 族群：華人對 β blocker 較敏感，可能需要較低劑量；非裔美國人反應較差。
  • 調劑量指標：休息時心跳變慢、運動時心跳上升變少。

5. α1 阻斷劑：拔掉水管上的收縮插座

代表藥：prazosin、terazosin（半衰期 12 小時，一天一次）、doxazosin（半衰期 22 小時）。

  • 擋小動脈和小靜脈的 α1 → 阻力血管和容量血管一起放鬆。
  • 因為保留突觸前 α2 的負回饋（NE 會自己踩煞車），所以反射性心跳加快比 phentolamine 少；phentolamine 連 α2 也擋 → 放更多 NE 去刺激心臟 β1。
  • 因為血管放鬆後站立時血會積在腳，所以站姿血壓降得比躺姿多。
  • 首劑效應：第一劑吸收後站立血壓驟降（可能暈倒），脱水、限鹽的人更常見 → 第一劑要小、睡前吃。
  • 單獨用會留鹽留水 → 最好和 β blocker、利尿劑合用。
  • 特殊族群：男性高血壓＋良性攝護腺肥大最適合（同時放鬆攝護腺平滑肌）。
  • 其他副作用少且輕：頭暈、心悸、頭痛、倦怠；prazosin 可能抗核抗體陽性（無風濕症狀）；對血脂中性或略好（但未證實臨床好處）。
  • 非選擇性 α 阻斷劑 phentolamine、phenoxybenzamine：用於嗜鉻細胞瘤的診斷與治療，以及兒茶酚胺過量的情況（例如 clonidine 停藥症候群時 phentolamine＋β blocker）。

各論三 直接血管擴張劑：把水龍頭直接轉鬆

直接放鬆小動脈平滑肌 → 因為交感反射完整，所以不會姿勢性低血壓或性功能障礙；但會反射性心跳加快、renin 上升、留鹽留水 → 要配 β blocker＋利尿劑。

hydralazine（口服長期用）

  • 只擴張小動脈。早期因為很快產生耐受（tachyphylaxis）被認為不好用，合併治療後才發揮，重度高血壓特別有用。

  • 因為牢牢結合在血管組織，所以藥效比血中濃度持久（半衰期 1.5–3 小時）→ 一天 2–3 次。
  • 副作用：頭痛、噓心、厭食、心悸、冒汗、潮紅；缺血性心臟病人的反射性心搏過速可誘發心絞痛或心律不整。
  • 類紅斑性狼瘡症候群：≥ 400 mg/d 時 10–20%，主要是慢乙醛化者；關節痛、肌痛、皮疹、發燒；不傷腎、停藥可逆。另有周邊神經病變、藥物熱。
  • hydralazine＋硝酸鹽：心衰竭有效，特別是非裔美國人的高血壓＋心衰竭。
  • 課本外補充：懷孕高血壓常用（與 labetalol、methyldopa、nifedipine 並列）。

minoxidil（口服、最強）

  • 活性代謝物 minoxidil sulfate 打開平滑肌 K⁺ 通道 → 膜穩在休息電位、不易收縮。只擴張小動脈。
  • 因為效力比 hydralazine 更強，反射性交感刺激和留鹽留水也更強，所以一定要配 β blocker＋loop 利尿劑。
  • 適用：hydralazine 最大劑量無效、或腎衰竭合併重度高血壓。
  • 副作用：心搏過速、心悸、心絞痛、水腫（配套藥不足時）；頭痛、冒汗；多毛症（女性特別困擾）→「一個人的副作用變成另一個人的治療」：外用 minoxidil（Rogaine）治禿頭。

sodium nitroprusside（靜脈、急症王牌）

  • 動脈＋靜脈都擴張 → 降阻力也降靜脈回流；活化鳥苷酸環化酶（放 NO 或直接刺激）→ cGMP 上升 → 平滑肌放鬆。
  • 沒有心衰竭時：血壓降、心輸出量不變或略降；有心衰竭、低心輸出時：因為後負荷下降，心輸出量反而上升。用於高血壓急症與嚴重心衰竭。
  • 起效極快，停藥後 1–10 分鐘就退 → 用輸注幫浦＋動脈導管持續監測。
  • 怕光 → 每次現配、用不透光鋁箔包住、數小時更換。劑量 0.5 起、最高 10 mcg/kg/min；高速超過 1 小時可能中毒。

代謝路線＝副作用路線：

  1. 進紅血球 → 放出 NO（降壓）＋氰化物（CN⁻）。
  2. 氰化物經粒線體的 rhodanese＋硫供應者 → 硫氰酸鹽（毒性較低）→ 分布在細胞外液、慢慢經腎排除。
  • 氰化物中毒（最嚴重）：代謝性酸中毒、心律不整、過度低血壓、死亡 → 解毒：sodium thiosulfate（提供硫）、hydroxocobalamin（和 CN⁻ 結合成無毒的 cyanocobalamin，即維生素 B12）。
  • 硫氰酸鹽中毒：用好幾天以上、尤其腎功能差時累積 → 無力、定向感混亂、精神病、肌肉痙攣、抽搐；血中濃度 > 10 mg/dL 確診。
  • 罕見：延遲性甲狀腺低下（硫氰酸鹽擋甲狀腺攝碘）、變性血紅素血症。

diazoxide

  • 打開 K⁺ 通道：平滑肌（擴張小動脈）＋胰臟 β 細胞（少放胰島素）。
  • 以前靜脈打來治高血壓急症；當年固定打 300 mg 造成過度低血壓 → 中風、心肌梗塞；反射性交感可誘發心絞痛、心衰竭 → 缺血性心臟病避免。
  • 現在：口服治胰島素瘤等高胰島素造成的低血糖（3–8 mg/kg/day 分三次）。
  • 副作用：高血糖（就是上面那個機轉，腎功能不全者更常見）。
  • 結構像 thiazide 卻沒有利尿作用，反而留鹽留水。和白蛋白高度結合 → 慢性腎衰竭（結合下降）要減量；先給 β blocker 效果更強。

fenoldopam

  • 周邊多巴胺 D1 致效劑 → 小動脈擴張＋排鈉；(R)-異構物有活性。
  • 經結合作用快速代謝、半衰期 10 分鐘、靜脈連續輸注 → 高血壓急症、術後高血壓。
  • 副作用：反射性心搏過速、頭痛、潮紅；會升高眼壓 → 青光眼避免。

鈣離子通道阻斷劑（CCB）

擋小動脈平滑肌的 L 型鈣通道 → Ca²⁺ 進不來 → 不收縮。降壓效果各藥差不多，差在「偏血管」還是「偏心臟」。

  • 適合：合併心絞痛的高血壓；非裔美國人反應好。

硝酸鹽

主要用於缺血性心臟病，有時用於高血壓急症（靜脈 nitroglycerin）；放 NO、也擴張靜脈（詳見第 12 章）。

各論四 RAAS 抑制劑：關掉腎臟發出的「轉緊水龍頭＋留水」命令

renin → Ang I → Ang II → AT1 受體／醛固酮這條命令鏈，切在哪一節，就看那一節「順便還管什麼」來推副作用。

命令鏈怎麼走

  1. 腎臟近腎絲球細胞放 renin。觸發：腎動脈壓下降、交感神經（β1）、遠端小管的鈉量或濃度改變。
  2. renin 把 angiotensinogen 切成 Ang I（十胜肽、沒活性）。
  3. ACE（主要在血管內皮）把 Ang I 切成 Ang II（八胜肽，強力收縮小動脈）。同一個酶素也叫 kininase II，負責分解緩激肽（bradykinin，會擴張血管）。
  4. Ang II 接 AT1 受體 → 小動脈收縮、留鈉；Ang II 和 Ang III 都刺激醛固酮 → 集尿管保鈉保水。
  • 心臟等組織也有自己的 Ang II 生產線 → 可能造成心肌肥厚；ACEI 也能擋。
  • 約 20% 原發性高血壓 renin 偏高、20% 偏低；renin 高的情況（腎動脈狹窄、惡性高血壓、用過限鹽或利尿劑後）對這類藥反應最好。但個人 renin 高低和降壓反應關聯不好 → 不需要先驗 renin。

腎絲球的「出口夾子」：理解 ACEI、ARB 的腎臟效果

課本說 ACEI 讓出球小動脈阻力下降、降低腎絲球內壓。比喻：腎絲球像一段濾網水管，Ang II 會夾緊「出口」（出球小動脈），讓濾網裡維持高壓好繼續過濾。

  • 糖尿病、慢性腎病：濾網長期被高壓撐壞 → ACEI、ARB 鬆開出口夾子 → 腎絲球內壓下降 → 蛋白尿減少、腎功能穩定（即使血壓沒降也有效）→ 糖尿病即使沒有高血壓也建議用。
  • 雙側腎動脈狹窄（或獨腎的腎動脈狹窄）：入口已經窄了，腎臟全靠夾緊出口撐住過濾壓 → ACEI、ARB 一鬆開，過濾壓崩掉 → 急性腎衰竭。

ACE 抑制劑（ACEI）

代表藥：captopril；enalapril（prodrug，水解成 enalaprilat；enalaprilat 只有靜脈劑型，用於高血壓急症）；lisinopril（enalaprilat 的 lysine 衍生物）；benazepril、fosinopril、moexipril、perindopril、quinapril、ramipril、trandolapril 是長效藥，全是 prodrug，主要在肝臟水解活化。

降壓兩條路：

  • 少了 Ang II → 小動脈放鬆、醛固酮變少。
  • 緩激肽分解變少 → 緩激肽累積 → 刺激 NO、前列環素 → 血管擴張。證據：緩激肽受體拮抗劑 icatibant 會削弱 captopril 的降壓。

特色：

  • 主要降低周邊阻力，心輸出量、心跳不太變；因為不會反射性交感活化（壓力感受器被往下重設或副交感增強），所以缺血性心臟病可以安全使用。
  • 心衰竭、心肌梗塞後很有用；高心血管風險者可能減少新發糖尿病。
  • 最大降壓幅度常 < 10 mm Hg，但長期保護腎臟、心臟的好處大。
  • 排除：除了 fosinopril、moexipril，都主要經腎排除 → 腎功能不全要減量。
  • 藥動：enalaprilat 服藥後 3–4 小時達峰、半衰期約 11 小時；lisinopril 半衰期 12 小時（一天一次 10–80 mg）。

血管張力素受體阻斷劑（ARB）

代表藥：losartan、valsartan（最早上市），azilsartan、candesartan、eprosartan、irbesartan、olmesartan、telmisartan。

  • 擋 AT1 受體 → Ang II 從哪條路做出來都沒用。
  • 因為不影響緩激肽，所以乾咳、血管性水腫少（但仍可能發生）→ 最常給 ACEI 受不了的人。
  • 因為 ACE 以外還有其他酶素能做出 Ang II，所以擋受體理論上比擋 ACE 更完整。
  • 心衰竭、慢性腎病的好處和 ACEI 相似；副作用也相似，包括懷孕禁用、高血鉀、腎功能惡化。
  • losartan 有活性代謝物（半衰期 3–4 小時），中度腎功能不全不用減量（表 11–2）。

直接 renin 抑制劑：aliskiren

  • 口服、擋 renin 的酶素活性 → 血中 renin 活性、Ang I、Ang II、醛固酮全部下降。
  • 因為 ACEI、ARB、利尿劑會讓身體「反彈」放更多 renin，而 aliskiren 連這個反彈也一起壓掉，所以理論上可加強它們；但實際雙重阻斷沒有明顯好處、副作用多 → 不建議。
  • 降壓幅度與安全性和 ACEI、ARB 相當；副作用：高血鉀、腎功能受損；懷孕禁用（潛在致畸）。

不要把 RAAS 擋兩次

ACEI＋ARB、ACEI 或 ARB＋aliskiren：近年試驗顯示毒性（高血鉀、腎功能惡化）增加 → 不建議合併。

同一條命令鏈上的其他藥

  • spironolactone、eplerenone 擋命令鏈最後一節（見各論一第 6 點）。
  • β blocker 擋 β1 → 少放 renin（見各論二第 4 點）。

臨床用藥：怎麼挑藥、怎麼組合、急症怎麼降

先排除續發性原因與改生活習慣，第一線從 thiazide、ACEI、ARB、CCB 挑；有合併症就挑「一顆藥治兩個病」；急症只先降約 25%。

開藥前

  • 至少三次不同門診量到偏高才算持續性高血壓；動態血壓監測最能預測風險。單純收縮期高血壓、老年高血壓也要治療。
  • 停掉會升壓的東西：擬交感神經的鼻塞藥、NSAIDs、口服避孕藥、部分草藥。
  • 非藥物治療：
    • 限鈉：美國平均每天約 200 mEq，目標 70–100 mEq（烹調時與上桌後不加鹽、少吃加工食品）。
    • 多蔬果、低脂乳製品、少飽和脂肪；酒每天不超過 2 杯。
    • 減重：體重過重的輕中度高血壓者，最多 75% 可回到正常；規律運動在部分研究有效。
  • 降壓目標：SPRINT 等研究建議心血管高風險者收縮壓目標 120 mm Hg；60 歲以上收縮壓 > 150 mm Hg 要治療。量血壓要量躺、坐、站三種姿勢。

第一線與加藥順序

  • 第一線：thiazide、ACEI、ARB、CCB 都證實能減少併發症。
  • 大型試驗（ALLHAT，課本未寫名稱）：chlorthalidone 減少冠心病死亡、非致命心肌梗塞和其他藥一樣好；預防心衰竭優於 amlodipine、預防中風優於 lisinopril。
  • β blocker 減少心血管事件較差 → 不當單純高血壓第一線。
  • 一顆不夠 → 加「不同機轉、不同副作用」的第二顆（stepped care）；三顆常用「利尿劑＋ACEI 或 ARB＋CCB」；第四顆考慮 β blocker 或 clonidine；頑固型可加 spironolactone。
  • 固定劑量複方：無法分別調劑量，但藥丸少、服從性較好。

高血壓急症

什麼情況：合併血管損傷（惡性高血壓）或血流動力學併發症（心衰竭、中風、主動脈剝離）。常見於控制差或突然停藥的人。

  • 惡性高血壓的惡性循環：小動脈發炎壞死 → 腎臟受損放更多 renin → Ang II、醛固酮上升 → 血壓更高。
  • 高血壓腦病變：劇烈頭痛、意識混亂、焦慮；視力模糊、噓心嘔吐、局部神經症狀；12–48 小時內可能抽搐、昏迷、死亡。

  • 加護病房、動脈導管連續監測；記錄輸入輸出、每天量體重。

  • clonidine：反彈高血壓危象 → 恢復 clonidine 或給 α＋β 阻斷劑。
  • β blocker：心絞痛加重、心肌梗塞風險 → 漸減。

解題 SOP＋練習題

遇到沒背過的題目，照這四步推，多數可以刪到剩一個答案。

四步驟

  1. 定位：這顆藥打在哪個控制點（水龍頭、儲水袋、幫浦、淨水廠、命令鏈）或腎元哪一段？
  2. 少了什麼：那個零件原本負責什麼？被擋之後，什麼東西變多、變少？
  3. 反撲：身體會怎麼補償？（交感上升心跳快、renin 上升、留鹽水、下游段多收鈉、換出 K⁺、H⁺）
  4. 族群：題目給了什麼病人（懷孕、氣喘、腎動脈狹窄、肝硬化、痛風、攝護腺肥大、憂鬱）？先刪掉禁忌。

練習題（答案跟在題目下方）

  1. 病人用 furosemide 後尿鈣、尿鎂上升，改用 HCTZ 後尿鈣反而下降。最好的解釋？ (A) furosemide 擋 PTH 受體 (B) loop 消除 TAL 的腔內正電；thiazide 讓 DCT 細胞內 Na⁺ 下降而加強 Na⁺/Ca²⁺ 交換 (C) thiazide 增加維生素 D (D) loop 增加 Ca²⁺ 通道
    • 答案 B。TAL 的 Ca²⁺、Mg²⁺ 靠 K⁺ 回流的正電從縫隙推回；DCT 的 Ca²⁺ 走專用門，細胞內 Na⁺ 越少，交換器越賣力。
  2. Liddle 症候群的病人，下列何者最有效？ (A) spironolactone (B) eplerenone (C) amiloride (D) acetazolamide
    • 答案 C。鈉門自己卡開、不靠醛固酮 → 撕命令沒用，要鎖門。
  3. 肝硬化病人為什麼不宜用 acetazolamide？
    • 尿變鹼 → NH₄⁺ 變 NH₃ 回到血液 → 血氨上升、肝腦病變。
  4. 雙側腎動脈狹窄的病人開始用 captopril 後肌酸酐急升，原因？
    • 腎臟靠 Ang II 夾緊出球小動脈維持過濾壓；ACEI 鬆開後過濾壓崩掉。
  5. 下列何者會使 clonidine 降壓作用減弱？ (A) 三環抗憂鬱劑 (B) HCTZ (C) amlodipine (D) losartan
    • 答案 A（TCA 有 α 阻斷作用）。
  6. 腎衰竭病人連續打 nitroprusside 四天，出現定向感混亂、肌肉痙攣、抽搐，最可能是什麼蓄積？
    • 硫氰酸鹽（腎臟排不掉；> 10 mg/dL 確診）。急性氰化物中毒則給 sodium thiosulfate、hydroxocobalamin。
  7. 為什麼 minoxidil 一定要和 β blocker 及 loop 利尿劑併用？
    • 強力擴張小動脈 → 壓力感受器反射使心跳加快（β blocker 擋）；renin、醛固酮上升留鹽水（loop 擋）。
  8. 男性高血壓合併良性攝護腺肥大，開立 doxazosin。第一次服藥要注意什麼？
    • 首劑效應 → 第一劑小量、睡前服用；脱水或限鹽者更常見。
  9. 懷孕高血壓的原文書首選？哪一類一定要避開？
    • methyldopa；ACEI、ARB、aliskiren（胎兒低血壓、無尿、腎衰竭）。
  10. 心衰竭病人長期用 loop 後出現低血鉀性代謝性鹼中毒，又不能補生理食鹽水，可加什麼修正？
    • acetazolamide（排 HCO₃⁻ 修正鹼中毒，順便小量利尿）。
  11. 用 HCTZ 的老年女性出現低血鈉，為什麼 thiazide 比 loop 更容易這樣？
    • 脱水讓 ADH 上升＋稀釋段（DCT）被擋＋口渴喝水；而 TAL 仍在、髓質還鹹 → 水仍被吸回。loop 把髓質的鹹度也拆了，鹽和水一起丟。
  12. 用 methyldopa 一年的孕婦術前交叉配血困難，原因？
    • Coombs 試驗陽性（用超過 12 個月者 10–20%）。
  13. 哪一個 β blocker 靠放出 NO 擴張血管？ (A) labetalol (B) carvedilol (C) nebivolol (D) esmolol
    • 答案 C（labetalol、carvedilol 是擋 α1）。
  14. 鋰鹽造成的腎因性尿崩症，可以用哪兩種利尿劑？要監測什麼？
    • thiazide（減少流到稀釋段的水、提高內髓質滲透壓）或 amiloride（擋鋰經 ENaC 進入細胞）；要監測血鋰。
  15. 高血壓急症病人血壓 220/130 mm Hg，第一個降壓目標？為什麼不直接降到正常？
    • 數小時內降約 25%，舒張壓不低於 100–110 mm Hg；腦血流自動調節已習慣高壓，降太快會腦缺血。
  16. 使用 eplerenone 的病人改吃哪一個藥最可能造成高血鉀？ (A) amoxicillin (B) erythromycin (C) acetaminophen (D) famotidine
    • 答案 B（CYP3A4 抑制劑，eplerenone 濃度大增）。
